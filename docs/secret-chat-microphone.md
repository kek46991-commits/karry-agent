# シークレットチャットとマイク修復

## 実装

提供されたReact/TypeScript案を、現在のPython/FastAPIと単一HTMLチャットへ移植した。フロントエンドの全面置き換えや新しいDBは追加していない。

### シークレット

入力欄の「シークレット」トグルをONにすると、テキスト会話を独立した揮発メモリで処理する。OFFの通常チャットは従来のR2タスク履歴保存を維持する。メディア用PostgreSQLはシークレット処理から呼ばない。

`POST /api/chat`、`/chat`、`/run`、`/agent/run` は `is_secret` と `isSecret` を受け付け、返答にも両フラグを含める。矛盾する指定や文字列の `"true"` は拒否する。`/api/chat` は既存の `prompt` / `session_id` に加え、提示コードの `message` / `taskId` も別名として受け付ける。

```json
{
  "session_id": "選択済みタスクID",
  "prompt": "この会話は保存せずに返答してください",
  "is_secret": true,
  "secret_session_id": "32桁の小文字16進ID",
  "request_id": "この送信に固有の再送ID",
  "image_ids": [],
  "stream": true
}
```

`secret_session_id` は省略するとサーバーが発行する。UIはタブ内メモリだけで生成・保持し、URL・localStorage・sessionStorageに保存しない。会話内文脈・直近の再送照合も通常のタスクメモリと分離する。SSEは秘密入力をstartedイベントやトレースへ含めず、本人への返答表示だけを返す。同じ再送ID・入力の再送は既存返答を返し、モデルを重複実行しない。

同名キーが重複したJSONはHTTP 400で拒否し、先のtrueが後のfalseで通常保存へ変わる抜け道も防ぐ。秘密会話・再送キャッシュはプロセスのRAMだけなので、複数ワーカーや再デプロイを跨ぐ文脈・再送照合は共有されない。

秘密入力・返答は、通常履歴、通常の実行記録、DB/R2、自己修復ログ・パッチ生成へ書かない。要求スコープをJSON解析・入力検証前から設定し、エラー応答は固定の安全なメッセージへ整形する。ログ抑止は要求ごとのContextVarで行い、同時に処理される通常チャットのログや保存は止めない。

ON中はテキスト返答専用で、Geminiへツールを登録しない。画像保存・画像生成・成果物公開は通常モードで行う。既存の合言葉による `private_mode` は人格・非公開プロフィールの認証であり、「無保存」の指定とは別機能である。認証状態もシークレットの揮発セッションに分離する。

OFF・タスク切替・接続再設定・ページ終了時はUIの秘密表示を破棄し、通常履歴はGETで復帰する。`POST /api/secret/forget` に `{"secret_session_id":"32桁ID"}` を送ると、処理中でなければサーバーの揮発メモリも破棄する。UIはこれをbest-effortで呼ぶ。IDはリクエスト本文に含め、URLへ載せない。

### 保持の範囲

「無保存」は本アプリの永続保存をしない意味であり、処理中や同じ会話内の文脈にはRAMを使う。サーバーは最大100会話、各会話は最大40メッセージ・160KiBを保持する。30分以上非活動のエントリは、新たな要求がなくても60秒間隔の掃除で除去する。処理中の会話は除去しない。FastAPI終了時にも全て破棄し、プロセス再起動時は復元しない。

ブラウザのリロードでも秘密会話を復元しない。タブ終了時の破棄要求は通信状況により届かない場合がある。Geminiへ入力を送信する点は通常と同じであり、LLMやブラウザ音声サービス側の保持はサービス・アカウント設定に依存する。外部も含むゼロ保持や物理メモリの消去保証ではない。HTTPのURL・ステータス等の技術的アクセス情報と、秘密の会話本文の記録も区別する。

### マイク

クリック時のみ `getUserMedia({audio:true})` で権限を要求し、取得した全Trackを停止する。`SpeechRecognition` / `webkitSpeechRecognition` を検出し、`ja-JP`、継続・途中結果、start/end/errorを管理する。手入力を残して中間・確定認識を合成する。

権限待ちの二重開始、録音の重複開始、タスク/モード変更後の遅い認識結果を防ぐ。停止、送信、タスク切替、シークレット切替、pagehide時に認識を停止/中断する。権限拒否、デバイス不可、ネットワーク、非HTTPS、未対応は日本語で案内する。音声データを本アプリへアップロード・録音保存しない。

実際の音声認識は利用端末のブラウザ対応とマイク権限に依存する。DOMモックで挙動を検証しており、実端末の音声入力・外部モデルのライブ送信は今回実行していない。
