# SadTalker統合の実装項目

- [ ] RenderはCPUのみのためローカルSadTalker推論を導入せず、画像とTTS音声を外部SadTalker環境へ送信し、口パクMP4を取得する非同期アダプターを実装する。待機・通信・ダウンロードには上限を設ける。
- [ ] 外部環境が重い、未設定、失敗した場合は既存の0円ローカル合成（静止画＋同じ音声）へ自動切り替え、口パク成功と静止画フォールバックを区別して保存・表示する。
- [ ] 動画作成画面に「人物を喋らせる（SadTalker）」トグルを追加する。既定OFFとし、外部への画像・音声送信と、失敗時の切り替えを明示する。
- [ ] 最新mainの既存機能を保持し、動画プロジェクト一覧に黄色（生成中）・緑色（完了）・赤色（エラー）のステータスランプを表示する。色だけでなく状態の文字も併記する。
- [ ] 長尺指定の秒数フォームを一覧／動画作成に追加または既存項目を改善し、指定秒数をAPIへ反映する。サーバーの対応範囲を超える値は明確に拒否する。
