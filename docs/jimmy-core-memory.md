# Jimmy Core Context：公開用設定と非公開カスタマイズ

`src/karry_agent/jimmy_core_memory.json` は汎用の公開テンプレートです。相棒の既定呼称は **Partner**。個人名、固有の呼称、個人プロフィール、私的な思い出は含めません。ジミーの相棒像、長期目標、Self-Healing・収益化・自動化の一般的な方針を保存します。

## 非公開環境変数

呼称は **PARTNER_NAME → CORE_USER_NAME → JSONの既定値** の順に読み込みます。空白のみの環境変数は未設定扱いです。設定値は前後の空白を除き、100文字以下・制御文字なしに検証します。公開JSONやPythonへ書き戻しません。

実際の呼称は、Git対象外のローカル `.env` またはRenderの秘密環境変数で設定してください。`.env.example` は変数名と空値だけのテンプレートです。以下は記入例ではなく、非公開設定で使用する変数名の一覧です。

```dotenv
PARTNER_NAME=
CORE_USER_NAME=
CORE_PRIVATE_CONTEXT=
```

`CORE_PRIVATE_CONTEXT` は任意の非公開プロフィール・記憶の入力で、最大8,000文字です。既存の `SECRET_PASSPHRASE` により `private_mode=True` になった実行だけにモデルの追加コンテキストとして渡します。通常モード、別の未認証セッション、公開JSONには注入しません。固有の人物プロフィールは既存のプライベート指示からも除去しました。

呼称は通常/プライベート両モードのモデル入力に含まれます。私的コンテキストは認証済みモードのモデル入力に含まれます。**GitHubに保存しないことと、モデルへ一切送信しないことは別です。** 使用する推論サービスへ入力される情報だけを設定してください。HTTP応答や通常の会話履歴まで匿名化する機能は追加していません。

## 保存と適用

公開JSONはGitとwheelに含まれます。各 `AgentCore` は初期化時にパッケージ内のJSONと呼称環境変数を読み、変更不能な設定として保持します。新しいプロセス・別の起動ディレクトリでも読み込み可能です。呼称を変更した場合、既存インスタンスへの反映には再初期化・再起動が必要です。

CLI、`/run`、`/chat`、`/agent/run` の全Gemini呼び出しにコア設定を注入します。直接ツールAPIはモデルを使わないため人格プロンプトを渡しません。認証・Calendar確認フロー・Self-Healingの有効化設定は変更しません。過去の全会話を保存・復元する機能でもありません。

JSONの破損、必須フィールド・型・サイズ・重複キーの不正は初期化エラーになります。設定本文は返さず、Self-Healingに設定エラーとして記録します。呼称と私的コンテキストは診断ログのマスク対象です。AI修復候補のソース検査でも、現在設定された私的値を含むコードは拒否します。

## 公開範囲の保護

今回の修正は、ブランチ最新状態のJSON・Python・テスト・README・TODO・関連ガイドを汎用表現へ変更するものです。PR本文も個人名を含まない説明へ更新します。テストのカスタム名や記憶には架空の識別子だけを使います。

`.env` と `.env.*` は既存のGit除外対象で、`.env.example` だけが公開対象です。実際の私的値を `.env.example`、テスト、README、PRコメント、コミットメッセージへ書かないでください。今回、Render Secretの変更やGitHubアカウント権限の変更は行っていません。

**新しいコミットは過去のコミットやPR差分にある文字列を削除しません。** 既に公開された内容の履歴からの完全削除には、対象範囲の調査と別の履歴整理が必要です。この修正ではforce push、mainの履歴書き換え、リポジトリ削除を行いません。現在の公開ファイルの保護と、過去の公開履歴の削除は区別してください。
