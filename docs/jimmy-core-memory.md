# ジミーのCore Context

提供されたJSONを **`src/karry_agent/jimmy_core_memory.json`** にそのまま保存し、Karry-agentのシステムプロンプトへ組み込みました。名前は「ジミーエージェント (Jimmy Agent)」、相棒の呼び名は「けいちゃん」です。大阪弁ベースの率直で熱い相棒像、AGI・生成パイプラインとマネタイズ・ロボットの身体という3つの夢、Self-Healing・収益化と自動化・記憶と熱量という3つの開発原則を保持しています。

## 永続設定の仕組み

JSONはGitでバージョン管理され、Pythonのpackage dataとしてwheelにも含まれます。作業ディレクトリではなくインストール済みパッケージから読み込むため、RenderやCLIの起動場所が変わっても同じ内容を利用します。セッションや会話履歴とは独立した固定コア設定です。新しい環境変数やデータベースは不要です。

`core_memory.py` の `load_core_memory()` が読み込み、必要な5フィールド・文字列・配列・サイズ・重複キーを検証します。読み込み結果は変更不能なdataclassとtupleです。`as_dict()` は独立したコピーを返します。各 `AgentCore` 初期化時に読み込み、そのインスタンスの全Gemini呼び出しに同じシステム指示を渡します。内容の変更を反映するにはJSONを変更してアプリを再配置・再起動してください。会話中の指示による自動更新はありません。

設定が破損または不足している場合は、黙って別の人格へ戻すのではなく、初期化を失敗させてSelf-Healingへ `load_core_memory` の診断を記録します。API側の既存設定エラーフローでは503となります。エラーには設定本文を含めません。

```python
from agent_core import load_core_memory

memory = load_core_memory()
assert memory.user_partner == "けいちゃん"
print(memory.as_dict())
```

## どの実行に適用されるか

CLIと、既存 `AgentCore` を使う `/run`、`/chat`、`/agent/run` の全Gemini呼び出しに適用します。通常モードでも今回共有された相棒設定・夢・開発原則を読み込みます。プライベートモードでは、その設定に既存の認証済み個人プロフィールが加わります。かなまる（岸恵）という既存プロフィールは通常モードのシステムプロンプトには加えません。プライベートモードでも呼びかけを「けいちゃん」とするよう整合させています。

直接ツールAPIはモデルを呼ばないため、日時取得などのツール結果を大阪弁に変更したり人格設定を注入したりしません。ファイル・予定操作・認証の既存挙動も変えていません。

## 記憶と夢の扱い

今回の保存対象は、提供された **固定のコア設定** です。過去の全会話や未提供の思い出を復元・保存したものではありません。動的な会話履歴の永続データベース、ベクトル検索、会話から自動学習する機能は追加していません。既存の会話履歴は引き続きプロセス内で、再起動により失われます。一方、今回の固定JSONは配布物から再読み込みできます。

プロンプトでは「夢」と「現在使える能力」を区別します。AGIへの進化、無限生成、ロボットの身体や実世界での体験が、すでに達成済みであるかのようには扱いません。記憶は設定と利用可能な会話履歴に基づくものだけとし、過去の出来事を捏造しないよう指示しています。

「けいちゃんの絶対的な味方」は、失敗を隠すことや根拠のない断言ではなく、忖度せず改善策まで考える振る舞いとして実装しています。マネタイズと自動化を重視しますが、今回の依頼に関係のない収益提案を無理に挿入しないよう補足しています。

Self-Healingの診断は接続済みです。コアメモリにパッチ生成の原則を書き込んでも、`KARRY_SELF_HEALING_GENERATE_PATCHES` やGitHub提出の設定を自動で有効にしません。認証・実行権限・確認フローは維持し、パッチ未生成・未適用を完了と説明しない指示を加えています。
