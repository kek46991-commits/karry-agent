# SadTalker外部連携

最新main（PR #35）のCPU口パク、ステータスランプ、既存動画生成とSQLプロジェクトAPIを保持します。Render内ではSadTalkerモデルやTorchを動かさず、設定したHugging Face Gradio Spaceへ検証済み人物画像と既存TTSのWAVを送ります。専用の非同期アダプターは送信・待機・ダウンロードを一度だけ実行し、期限超過や異常応答を安全な理由コードで返します。SadTalker経路のCPU処理は既存FFmpegによる軽量合成だけです。

`/api/video/jobs`へ`sadtalker`を追加し、ONの場合は有料動画プロバイダーではなくSadTalker→既存ローカル合成の経路を使います。既存の`lip_sync`だけを指定するAPIはCPU口パクのまま保持します。音声は一度だけ生成し、画像と実音声があれば外部連携を試します。未設定・混雑・失敗・音声生成失敗はローカルへ戻し、完成動画が口パクなのか静止画合成なのかをAPIとUIに明示します。SQLプロジェクトAPIと無料プレビューボタンはそのまま保持します。

外部接続先は既定では空で、UIのトグルも既定OFFです。ON時は外部への画像・音声送信を明示します。人物画像は利用権・本人同意を確認して利用します。無料公開Spaceは稼働や待ち時間を保証しません。確認時点の公式SpaceはBuild errorで、これを稼働済みとは扱いません。

構成は`src/karry_agent/sadtalker.py`（非同期アダプター）、`sadtalker_worker.py`（有限時間の外部SDK通信）、`video_suite_api.py`（既存ジョブ経路への統合）、`video_suite.py`（結果の再合成と公開ビュー）、`static/index.html`（トグルと結果表示）です。既存UIの視覚スタイルを引き継ぎ、新しい装飾や別アプリは作りません。

動画カードとSQL動画プロジェクト一覧へ、生成中は黄色・完了は緑色・エラーは赤色のランプと状態文字を併記します。SQLプロジェクト一覧は所有者認証付きで明示的に読み込み、各カードの長尺指定（秒数）を既存PATCH API・楽観ロックで保存します。サーバーの現在の範囲は1～120秒で、範囲外や生成中の編集を拒否します。保存は設定変更だけで、外部の再生成を勝手に実行しません。
