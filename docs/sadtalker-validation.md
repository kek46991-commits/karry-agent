# SadTalker・動画プロジェクトUIの検証

この修正は最新mainのPR #35・#36を取り込み、CPU簡易口パクと既存HTTP/Gradio接続、静止画／簡易口パク／人物アニメーションの3モードを保持します。新しいHF Space経路は軽量Gradioクライアントを期限付きの子プロセスで動かし、RenderへSadTalkerモデルやTorchを導入しません。

外部連携のテストでは、送信前のAPI引数検査、画像・音声のFileDataアップロード、同一SpaceからのMP4取得、認証値の送信範囲、タイムアウト・キャンセル時の子プロセス回収、未設定・失敗時の同音声ローカルフォールバックを確認しました。HF SDKは1.11.0と2.7.2の呼び出し差を確認し、実行テスト環境は2.7.2を使っています。

実FFmpegとffprobeを使用して、ローカルフォールバックMP4の動画・音声ストリーム、指定秒数と縦横比を確認しています。外部モデルの成功応答はモックで検証しており、実際のSadTalkerモデルによる口パク生成は未検証です。確認した公式の無料SpaceはBuild errorだったため、無料環境の稼働や利用枠を保証しません。

プロジェクト一覧は既存の認証付きSQL APIへ接続し、ステータスランプと状態文字、1～120秒の保存フォームを実装しています。更新競合・生成中の編集禁止・シークレットモード・別トークンや別タスクへの遅延応答を防ぐ処理をテストし、SQL一覧とPATCH接続の読み取り専用レビューでは確定重大不具合はありませんでした。秒数保存は設定変更のみで、外部への自動再生成は実行しません。

この作業ではGitHub修正PRを作成します。mainのマージやRender本番デプロイは実施していません。

最終検証結果: 全Pythonテスト922件成功・13件skip、UIテスト75件成功、compileall・pip check・git diff --check成功です。既存のDeprecationWarningのみで失敗はありません。
